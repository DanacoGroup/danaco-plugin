# narzedzia-zespolu

Przykładowa wtyczka z marketplace `zespol-przyklad`: skill `zasady-commitow`, agent
`recenzent`, hook formatowania po edycji (opcja `formater`), plik wykonywalny `stan-repo`,
serwer MCP dokumentacji. Instalacja: `claude plugin marketplace add <ścieżka marketplace>`,
`claude plugin install narzedzia-zespolu@zespol-przyklad`; jedna sesja: `--plugin-dir`.
